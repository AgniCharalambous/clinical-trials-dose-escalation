# clinical-trials-dose-escalation
Clinical trials dose-escalation analysis using the 3+3 design in R.

Postgraduate coursework project developed as part of the MSc in Biostatistics and Health Data Science.

This project explores the operating characteristics of the 3+3 dose-escalation design under different toxicity scenarios using R.

## Topics
- Clinical trial design
- Dose-escalation methods
- Transition probabilities
- Statistical analysis
- Biostatistics

## Tools
- R
- R Markdown
